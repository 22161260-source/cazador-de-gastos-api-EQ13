## Descripción

Cazador de Gastos es una API REST desarrollada en Laravel que ayuda a los usuarios a detectar gastos innecesarios mediante el análisis de ingresos y gastos. El sistema genera recomendaciones y alertas para mejorar la administración financiera.

## Tecnologías

- Laravel
- PHP
- MySQL
- Sanctum
- Bruno
